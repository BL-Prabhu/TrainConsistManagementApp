# UC8 - Filter Passenger Bogies Using Streams

## 📌 Overview
This use case demonstrates filtering of bogies using Java Stream API.

## ❗ Problem in UC7
- Sorting only arranges data
- Cannot filter based on conditions
- Requires manual loops

## 🎯 Objective
Filter bogies based on seating capacity using Streams.

## 🛠️ Technologies Used
- Java
- Stream API
- Lambda Expressions
- Collections (List)

## ▶️ Flow
1. Create bogie list
2. Convert to stream
3. Apply filter condition
4. Collect results
5. Display filtered bogies

## 📊 Sample Output

Bogies with capacity > 60:
Sleeper (72)
General (90)

## 🚀 Key Concepts
- stream()
- filter()
- collect()
- Functional programming

## ✅ Benefits
- Cleaner code
- No manual loops
- Easy to maintain
- Declarative style
