# TrainConsistManagementApp# 🚆 Train Consist Management App

A console-based Java application that simulates railway train consist management.

---

## 📌 Features (UC1)

- Initialize train consist
- Display initial bogie count
- Show current train composition

---

## 🧱 Tech Stack

- Java 8+
- Collections Framework (ArrayList)
- OOP Principles

---

## 📂 Project Structure

- app → Entry point
- service → Business logic
- model → Data representation
- util → Helper utilities

---

## ▶️ How to Run

```bash
javac -d bin src/main/java/com/train/**/*.java
